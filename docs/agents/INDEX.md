# Agents Index - AlbumSL

Este índice existe para no duplicar la selección de agentes en `AGENTS.md`.

## Mapa de agentes

| Agente                             | Archivo detallado                         | Cuándo leerlo                                                                      |
| ---------------------------------- | ----------------------------------------- | ---------------------------------------------------------------------------------- |
| Product / Spec Agent               | `docs/agents/product-spec-agent.md`       | Cambios de alcance, producto, reglas de negocio, roadmap o criterios de aceptación |
| Architect / DevOps Agent           | `docs/agents/architect-devops-agent.md`   | Estructura, monorepo, scripts, CI/CD, ambientes, decisiones técnicas               |
| Frontend Agent                     | `docs/agents/frontend-agent.md`           | React, rutas, hooks, componentes, UX y mobile-first                                |
| Backend / Firebase Functions Agent | `docs/agents/backend-functions-agent.md`  | Backend, Admin SDK, Functions, adapters e integración Firebase                     |
| Domain / Application Agent         | `docs/agents/domain-application-agent.md` | Entidades, reglas puras, casos de uso, puertos y helpers testeables                |
| QA Agent                           | `docs/agents/qa-agent.md`                 | Tests, regresión, validación y smoke checks                                        |
| Security / Ciberseguridad Agent    | `docs/agents/security-agent.md`           | Firestore Rules, permisos, ownership y abuso del cliente                           |
| Data / Content Agent               | `docs/agents/data-content-agent.md`       | Dataset de figuritas, rarezas, distribución, placeholders y copyright              |
| Release / Operations Agent         | `docs/agents/release-operations-agent.md` | Deploy, ambientes, variables, troubleshooting, logs y checklist de release         |

## Regla

- Los agentes son roles de trabajo, no procesos automáticos.
- Leé solo los archivos de agente que el router active para la tarea actual.
- No actives todos salvo que la tarea realmente cruce todo el sistema.
